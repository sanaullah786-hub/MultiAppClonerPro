# Privacy Policy: Multi App Cloner Pro

Last updated: 2026-11-23

Multi App Cloner Pro runs on your device. The developer does not operate a server for this app and does not collect,
sell or share personal data.

- **Stored locally:** clone profiles, network profile settings and logs, in the app's private storage. Proxy passwords are
  encrypted with the Android Keystore. Backup files are created only when you export them and never include passwords.
- **Apps you clone:** the app reads the APK file of an app you choose, or an APK file you pick, to run it in its own
  private data area. Data created inside a clone stays on your device.
- **Network:** the optional IP checker and proxy test contact the address you configure. Cloned apps make their own
  network connections exactly as they would normally.
- **Permissions:** the app may request access to list installed apps and to install packages. These are used only for the
  features you start.
- **Logs:** the "Copy engine log" button copies a log to your clipboard. It is shared only if you paste it somewhere.
